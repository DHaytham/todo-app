# To-Do App

A simple application where users can organise their daily tasks, set deadlines and plan important events.

## Project Status

Planning stage. Application development has not started yet.

## Learning goals

- Build accessible page structures with HTML.
- Create responsive layouts with CSS.
- Add interactivity and manage task data with JavaScript.
- Build reusable components with React.
- Develop a REST API and store data in a database.
- Implement user authentication and authorization.
- Deploy and maintain an application in the cloud.

## Roadmap

- [ ] Build the page structure with HTML
- [ ] Style the interface with CSS
- [ ] Add task management with JavaScript
- [ ] Save tasks in the browser
- [ ] Rebuild the interface with React
- [ ] Build a REST API and connect a database
- [ ] Add user accounts
- [ ] Deploy the application to the cloud
